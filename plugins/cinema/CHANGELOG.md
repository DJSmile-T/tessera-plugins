# Changelog

## 0.1.0
- First version: the films in a country's cinemas, coming soon or popular, from TMDB, as a cover flow of posters that
  moves on by itself, with the rating on the poster and the genres under the title. Filters for one genre and a
  lowest rating. Needs a free TMDB API key and a screen with plugin API 0.10. A board without pictures shows the
  titles as a list.
